# business-oriented-tourism-intelligence-dashboard
📊 Business-Oriented Tourism Intelligence Dashboard

📌 Background
Industri pariwisata membutuhkan pengambilan keputusan yang tepat terkait strategi harga, promosi, dan pengembangan destinasi. Namun, banyak keputusan masih dilakukan berdasarkan intuisi tanpa dukungan data yang terintegrasi. Dataset wisata ini menyediakan informasi penting terkait harga tiket (HTM), persepsi pengunjung (rating & jumlah ulasan), jenis destinasi, serta lokasi geografis, yang sangat relevan untuk analisis bisnis pariwisata. Dashboard ini dikembangkan untuk membantu pemangku kepentingan memahami hubungan antara harga, kepuasan pengunjung, dan popularitas destinasi guna mendukung keputusan strategis berbasis data.

🎯 Tujuan Dashboard
Tujuan utama dari dashboard ini adalah:
1. Menganalisis kesesuaian antara harga tiket dan kepuasan pengunjung
2. Mengidentifikasi destinasi dengan potensi peningkatan harga atau kebutuhan promosi
3. Menilai performa destinasi wisata berdasarkan jenis dan lokasi
4. Mendukung pengambilan keputusan bisnis dalam pengelolaan dan pengembangan destinasi wisata
